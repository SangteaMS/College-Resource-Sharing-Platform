# Contributing

1. Create a branch for your change, for example `git switch -c feature/short-description`.
2. Make and commit your changes, then push the branch and open a pull request for review.
3. Before submitting, run the test suite from the project root: `./mvnw test` on macOS/Linux or `.\mvnw.cmd test` on Windows.

Keep `.env` files, passwords, database credentials, `data/`, and `uploads/` out of commits. Use `.env.example` for placeholder variable names only.

Use fictional academic materials in examples, or materials you have permission to share. Do not include real students' personal information.
